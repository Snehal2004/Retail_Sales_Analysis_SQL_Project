# 🛍️ Retail Sales Analysis SQL Project

## 📌 Project Overview

**Project Title:** Retail Sales Analysis  
 
**Database:** `retail_db`  
**Tools Used:** MySQL Server, MySQL Workbench, SQL

This project focuses on analyzing retail sales data using SQL to uncover meaningful business insights. It demonstrates essential SQL skills used by data analysts, including database creation, data cleaning, exploratory data analysis (EDA), aggregate functions, filtering, grouping, subqueries, and window functions.

The goal is to transform raw retail sales data into useful insights that can support business decision-making.

## 🎯 Project Objectives

- **Database Setup:** Create a database and table to store retail sales data.
- **Data Cleaning:** Identify and handle missing or NULL values.
- **Exploratory Data Analysis (EDA):** Explore the dataset to understand sales patterns and customer demographics.
- **Business Analysis:** Answer business questions using SQL queries.
- **Insight Generation:** Identify sales trends, customer purchasing behavior, and product category performance.

## 🗂️ Database Structure

**Database Name:** `retail_db`  
**Table Name:** `retail_sales`

The `retail_sales` table contains the following columns:

| Column Name | Description |
|---|---|
| `transactions_id` | Unique transaction identifier |
| `sale_date` | Date of the transaction |
| `sale_time` | Time of the transaction |
| `customer_id` | Unique customer identifier |
| `gender` | Customer gender |
| `age` | Customer age |
| `category` | Product category |
| `quantity` | Quantity of products sold |
| `price_per_unit` | Price per unit of the product |
| `cogs` | Cost of goods sold |
| `total_sale` | Total sales amount for the transaction |

## 🛠️ Skills Demonstrated

## 📊 Business Questions Answered

This project explores retail sales through business-focused SQL queries, including:

1. Retrieve all sales transactions.
2. Identify customers who made purchases.
3. Analyze sales by product category.
4. Find transactions in a specific category with a minimum quantity sold.
5. Calculate total sales and the number of orders.
6. Identify the highest-selling product categories.
7. Calculate the average sale for each month and find the best-performing month in each year.
8. Analyze customer demographics and purchasing patterns.
9. Identify top customers based on spending.
10. Explore sales trends across different periods.
